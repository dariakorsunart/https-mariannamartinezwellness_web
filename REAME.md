# Marianna Martinez Wellness website

This repository contains the source code for the official **Marianna Martinez Wellness** website homepage. The site is designed to introduce visitors to Marianna Martinez's holistic health services, focusing on nutrition, metabolic balance, and energy medicine.

---

## 🌟 Overview

The homepage is the primary landing page for the wellness practice. It acts as a friendly and informative portal, encouraging visitors to explore services and book an appointment.


## Getting Started

To run this project locally, simply follow the steps below.

### Prerequisites

You only need a modern web browser to view the page.

### Installation

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/dariakorsunart/https-mariannamartinezwellness_web.git
    cd https-mariannamartinezwellness_web
    ```
2.  **Open the file:** Locate the `index.html` file and open it with your preferred web browser.

No server environment is strictly necessary as this is a static HTML page.

---

## Technology Stack

This website is built using standard front-end technologies:

* **HTML5:** For the page structure and content.
* **CSS3:** For styling, linked via `style.css`.
* **JavaScript:** Used for any interactive elements, linked via `index.js`.
* **Bootstrap v5.3:** Utilized for responsive layout components (included via CDN).
* **Google Fonts:** Multiple fonts are imported for aesthetic variety and branding.
